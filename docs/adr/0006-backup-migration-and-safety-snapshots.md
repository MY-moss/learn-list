# ADR 0006：备份版本迁移与替换前安全快照

## 状态

已接受。

## 决策

- 备份载荷使用显式 `schemaVersion`；当前版本为 3，同时兼容版本 1 和 2 的缺省字段。
- 加密备份使用 AES-GCM；密码不保存到应用设置。
- 导入先解析、校验引用、日期、枚举、大小和密码，再执行 Room 事务。
- 替换导入前自动导出加密安全快照；优先使用用户输入密码，否则生成随机密码并与快照一起写入私有目录。
- 快照最多保留最近 3 份，并清理超过 30 天的快照。
- 合并按实体更新时间选择可变记录，复习/阅读日志、纠正事件和专注记录按 ID 去重追加。
- 加密备份可携带应用私有目录中的自定义提示音；明文备份不携带音频，导入后重新写入新的私有文件名。

## 后果

误替换可以从本机快照恢复，旧备份仍可导入；快照密码文件必须和应用私有目录一起保护，不能当作对外导出的备份密码。

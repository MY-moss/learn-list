# ADR 0008：历史日历复用今日进度口径

## 状态

已接受。

## 背景

用户需要快速回看过去哪几天完成了学习，但历史页不能另造一套统计规则，否则日历百分比与今日驾驶舱会出现不一致；同时未来日期不应被误操作为补记入口。

## 决策

- 今日页提供按月日历入口，日期格直接复用 `DailyProgressCalculator` 的同一份输入和完成口径。
- 日期格展示完成百分比；没有必做行动的日期显示为无数据，不伪装成 100%。
- 过去日期可点击并回到今日驾驶舱查看详情；未来日期显示为禁用状态，日历不允许通过它进行补记。
- 日历只负责浏览和跳转，行动的新增、完成和纠正仍使用原有页面流程。

## 后果

历史回看与首页统计保持一致，用户能从月视图快速定位薄弱日期；但每天会重新计算多个日期的摘要，数据量很大时需要后续再评估缓存或分页优化。

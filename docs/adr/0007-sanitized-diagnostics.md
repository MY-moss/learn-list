# ADR 0007：只导出聚合信息的本地诊断报告

## 状态

已接受。

## 背景

通知、前台服务、更新安装和系统选择器等能力依赖设备环境。排查兼容性问题需要版本、Android API 和记录规模，但学习内容本身属于用户隐私，不能随诊断文件离开设备。

## 决策

- 诊断报告只在用户主动点击“导出脱敏诊断”后生成，并通过系统文件选择器保存。
- 报告包含应用版本、Android API、厂商/型号、各实体的总数/归档数/删除数，以及少量功能开关状态。
- 不导出标题、笔记、来源、标签、日期、实体 ID、路径、自定义音频和备份内容；厂商/型号中的控制字符也会被过滤并限制长度。
- 诊断报告使用独立格式标识，不进入备份导入流程，也不自动上传或发送到服务器。

## 后果

用户可以在不暴露学习内容的前提下提供基本环境信息；如果仍需定位具体数据问题，必须由用户另行选择并主动提供加密备份或日志。聚合报告不能替代完整备份，也不包含可恢复数据。

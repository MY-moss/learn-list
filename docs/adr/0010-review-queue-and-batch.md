# ADR 0010：复习队列与建议批次

## 状态

已接受。

## 背景

到期复习数量增加后，用户需要一个连续处理入口；但把队列硬截断会让逾期内容消失，也会让“建议每天处理 20 项”变成隐藏数据的限制。

## 决策

- 今日复习队列统一按逾期优先、已学习内容优先、下次日期升序排列。
- “开始一批”只选择当前队列中已完成首次学习的前 N 项；N 来自设置中的建议批次大小，最小为 1。
- 批量复习逐项保存反馈，保存期间锁定按钮；保存失败保留当前对话框，成功后自动进入下一项。
- 批次结束或用户主动退出后，剩余到期任务仍在今日页完整展示，可以单独处理。

## 后果

复习流程减少了频繁返回列表的操作，逾期优先规则也集中在可测试的领域策略中。首次学习任务仍保留单独的“学完”入口，避免把首次学习误标为复习反馈。

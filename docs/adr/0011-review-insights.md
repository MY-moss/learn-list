# ADR 0011：复习反馈洞察保持独立计量

## 状态

已接受。

## 背景

统计页原本能看到复习总量和按天趋势，但无法回答“哪些内容最近经常记不住”。如果把复习、阅读页数和专注分钟合成一个分数，用户又无法解释分数变化，也不利于调整学习负担。

## 决策

- 只在最近 28 天窗口内统计复习日志，并包含起止日期；未来日期、窗口外记录和“稍后”不计入反馈分布。
- 复习反馈保持“记得、模糊、忘记”三个独立数量，同时显示记得率，不与阅读页数或专注分钟混合加权。
- 薄弱项按模糊与忘记次数优先排序，再按忘记次数、最近复习日期和标题稳定排序；只展示前几项作为建议，不截断原始记录和今日复习队列。
- 统计逻辑放在纯领域模型中，UI 只负责将当前任务和项目名称映射到展示模型。

## 后果

用户可以快速找到需要优先回顾的内容，并能理解每个数字的单位。洞察榜单是辅助入口而不是新的任务队列，因此不会改变艾宾浩斯调度和积压可见性规则。

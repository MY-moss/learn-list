# ADR-0001：采用原生 Android 离线优先架构

- 状态：已接受
- 日期：2026-08-31

## 决策

首版使用 Kotlin + Jetpack Compose + Navigation + ViewModel，数据层使用 Room 保存学习实体，DataStore 保存轻量设置和正在进行的计时状态。应用不要求账号、远程 API 或常驻服务器。

## 原因

学习记录需要在无网络、通勤和权限受限的场景下可靠可用；原生 Android 能直接处理通知、AlarmManager、系统文件选择器和 APK 安装器。Room 的事务保证复习、阅读日志和备份导入不会只写入一半。

## 取舍

离线优先降低了隐私和运营成本，但首版没有跨设备同步；备份/恢复是明确的迁移边界。UI 和领域计算分层，便于未来加入同步而不把网络状态渗透到复习规则中。

## 后续约束

任何云同步设计必须先定义冲突规则、端到端加密和离线冲突测试，不能直接把 Room 表暴露给网络接口。

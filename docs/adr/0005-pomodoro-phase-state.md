# ADR 0005：番茄钟采用持久化阶段状态机

## 状态

已接受。

## 决策

- 阶段为 `WORK`、`SHORT_BREAK`、`LONG_BREAK`，按四轮循环推进。
- 工作阶段默认 25 分钟，短休 5 分钟，第四轮后长休 15 分钟。
- DataStore 保存阶段、轮次、剩余秒数、累计工作秒数、原始工作开始时间和可选项目/任务归属。
- 前台服务负责后台计时，AlarmManager 负责进程恢复后的兜底完成；通过开始时间去重写入专注记录。
- 暂停/继续保留实际秒数；跳过和取消不产生完整阶段统计；提前结束只记录实际工作秒数。
- 阶段结束默认停在下一阶段；用户可在设置里打开自动衔接。

## 后果

计时统计不再依赖 UI 生命周期，用户可以锁屏或离开应用。前台服务、通知权限和省电策略仍需在真实设备上验收。

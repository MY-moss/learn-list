# ADR 0003：用追加事件实现纠错，用软删除实现回收站

## 状态

已接受。

## 背景

学习记录可能被误记，用户需要改正当前计划，但历史统计和审计线索不能被悄悄覆盖；删除也需要有恢复机会。

## 决策

- 复习纠正写入 `review_corrections`，并更新学习任务的当前投影。
- 阅读纠正写入 `reading_adjustments`，用正负页数表示修正；原始 `page_logs` 保持不变。
- 项目、任务、阅读计划、待办、目标和倒计时使用 `deletedAt` 软删除。
- 默认查询排除软删除记录；回收站查询保留它们。
- 永久删除在 Room 事务中清理附属日志、纠正事件和关联提醒；不可恢复。

## 后果

历史记录可追溯、合并备份更安全，但统计读取时必须同时聚合原始日志和调整事件。

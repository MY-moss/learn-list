# ADR 0004：可恢复更新与安装前签名校验

## 状态

已接受。

## 决策

- 更新只来自稳定 GitHub Release，并要求 APK 和 SHA-256 资产。
- 下载写入 `.part` 文件，使用 HTTP Range 尝试断点续传；暂停或进程退出后保留部分文件。
- 下载状态由前台服务持久化到 DataStore，界面显示连接、续传、下载、摘要校验、证书校验和安装器交接。
- 下载完成的 APK 保留在应用私有缓存；系统安装器被取消、或用户先去开启未知来源权限后，可以重新校验本地包并再次交接，不重复下载。
- 安装前校验 HTTPS/允许域名、APK 包名、版本名、版本号不降级、SHA-256，以及当前安装包和下载包的签名证书摘要集合。
- HTTP 重定向逐跳限制在允许的 GitHub HTTPS 域名内，并限制 Release 元数据和摘要文件大小。
- 通过 Android 系统安装器完成用户确认，不做静默安装。
- 通过 `MY_PACKAGE_REPLACED` 和前台恢复回查安装结果；失败或取消不清除未完成状态。

## 后果

更新过程不会因为 Activity 被销毁而丢失；签名不一致的 APK 会被拒绝。系统安装器的取消行为只能通过下次恢复/检查间接识别，不能在所有 Android 版本得到统一回调。

## v0.2.7 后续升级进度

- [x] 稳定性：投递时重新检查项目、任务、倒计时状态；停用/归档/软删除后不再投递旧提醒。
- [x] 更新链路：GitHub Stable Release 自动/手动检查、断点续传、前台进度通知、暂停/恢复、SHA-256/包名/版本/签名证书校验和安装器交接。
- [x] 数据闭环：项目、任务、阅读、待办、目标、倒计时支持编辑、软删除、恢复和永久删除；纠错/阅读调整采用追加事件。
- [x] 复习与阅读：逾期优先但不隐藏积压，建议批次可调；阅读调整计入当天统计；待办支持项目关联和漏做轻提示。
- [x] 番茄钟：25/5/4 轮循环、暂停/继续/跳过、实际秒数、项目/任务绑定和阶段级声音/振动反馈。
- [x] 统计与交互：复习项、阅读页、专注分钟、待办分别统计；今日页支持历史日期回看和受控补记；首次引导不注入虚假数据。
- [x] 输入可靠性：创建、编辑、阅读纠正、复习纠正、倒计时和提醒失败时保留表单，成功回调后再关闭。
- [x] 日期一致性：表单日期选择器、倒计时编辑默认值、今日统计、专注记录、目标归因、更新检查时间与应用总览共享可注入 Clock/ZoneId。
- [x] 提醒一致性：一次提醒投递固定同一时区和本地日期，用于到期判断、摘要进度和通知动作。
- [x] 文档：统一领域词汇并补充数据纠错、更新校验、番茄阶段和备份迁移 ADR。

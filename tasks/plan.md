# Learn List 首版实施与验收

## 已实现

- [x] Android 单模块工程、包名 `com.mymoss.learnlist`、Android 8.0+。
- [x] Compose 导航骨架：今日、学习、待办、专注、统计、设置。
- [x] Room 实体、仓库、DataStore 设置和 1→2 阅读目标迁移。
- [x] 初次学习日期持久化、2→3 数据库迁移、待办按日期撤销和统一今日进度计算。
- [x] 艾宾浩斯复习调度、真实复习日志、隐藏资料、逾期可见。
- [x] 阅读页数日志、每日目标、截止日均摊、手动日目标调整。
- [x] 重复待办、必做行动、今日百分比、连续打卡、暂停/归档/恢复。
- [x] 番茄钟、进程重新创建后的计时状态恢复、前台服务持久通知、后台完成提醒、带提前提醒的倒计时、量化目标和热力图。
- [x] 固定提醒、每日摘要、通知权限、精确提醒权限和重启/时区变化后排程。
- [x] 加密/明文备份、大小/格式/密码校验、导入预览、合并/替换。
- [x] GitHub Release 检查、SHA-256 校验、系统安装器和 CI/Release 工作流；CI 已接入 API 36 Android 模拟器仪器测试。
